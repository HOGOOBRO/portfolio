Design System

디자인 시스템Design System

디자인도 감이 아니라,
규칙으로.Design by rules,
not by gut.

이 사이트를 지탱하는 규칙을 그대로 적어 둔 문서예요. 색·글자 크기·간격·움직임을 매번 감으로 고르지 않고 정해진 값에서만 고릅니다. 화면이 늘어도 결이 흐트러지지 않는 이유고요.This is the rulebook the site runs on. Color, type size, spacing, and motion are chosen from fixed values rather than by feel each time. That’s why the whole thing holds together as pages pile up.

00

원칙Principles

이 네 가지만 정해두면, 나머지 규칙은 저절로 따라와요.Decide these four, and every other rule falls into place.

01색 대신 위계로 말한다Hierarchy, not color

UI는 흑백만 씁니다. 강조는 색이 아니라 크기·굵기·여백의 차이로 만들어요. 화면에서 유일하게 색을 내는 건 작업물 이미지Image 자체입니다. 그래야 작업이 배경에 묻히지 않아요.The UI is black and white. Emphasis comes from size, weight, and space, not hue. The only color on screen comes from the work itself, so the work never gets lost in the background.

02한국어를 먼저 생각한 타이포Typography that starts with Korean

한글은 단어 중간에서 줄이 끊기면 읽기 불편해요. 그래서 띄어쓰기 단위로만 넘어가게(word-break:keep-all) 해뒀습니다. 라틴 제목은 Fraunces, 본문과 한글은 Pretendard, 라벨·수치는 JetBrains Mono로 역할을 나눴어요.Korean is hard to read when a line breaks mid-word, so lines break only at spaces (word-break:keep-all). Roles are split by face: Fraunces for Latin headings, Pretendard for body and all Korean, JetBrains Mono for labels and figures.

03여백은 화면 크기를 따라간다Space scales with the screen

고정 px 대신 clamp()로 최소·유동·최대를 함께 정합니다. 작은 화면에서는 답답하지 않을 만큼만 줄고, 큰 화면에서는 끝없이 벌어지지 않아요.Instead of fixed pixels, clamp() sets a minimum, a fluid middle, and a maximum. Small screens tighten only so far; large ones stop spreading.

04그리드의 원점은 하나One origin for the grid

12컬럼 중 1–2번은 메타 정보(라벨) 자리, 본문·수치·구분선Rules은 전부 3번 컬럼에서 시작합니다. 무엇 하나만 왼쪽으로 튀어나오지 않게, 원점을 하나로 고정했어요.Of twelve columns, 1–2 hold meta labels; body text, figures, and rules all start at column 3. One fixed origin so nothing juts out to the left on its own.

Both expose the same variable names (--fg, --bg, --rule), so components inside need no changes.

04

그리드Grid

12컬럼. 1–2번은 메타, 본문은 3번부터.Twelve columns. 1–2 for meta, body from 3.

진한 두 칸이 메타 열입니다. 오프셋은 100vw/12 단위로 계산해 화면 폭이 변해도 비율이 유지됩니다.The two darker cells are the meta column. Offsets are computed in 100vw/12 units, so proportions hold at any width.

메타 라벨Meta labelcol 1 – 2섹션 번호·이름, 역할, 연도처럼 본문을 거드는 정보Section number and name, role, year: what supports the body
본문 · 요약 · 수치Body · summary · figurescol 3 – 8읽는 글이 들어가는 자리. 한 줄이 너무 길어지지 않는 폭입니다.Where reading text lives, at a width that keeps lines from running long.
도판 · 표Figures · tablescol 3 – 10넓게 봐야 읽히는 것만. 시작점은 본문과 같습니다.Only what needs width. Starts where the body starts.
구분선Rules콘텐츠 오른쪽 끝까지To the right edge of the content화면 끝까지 긋지 않습니다. 선이 내용보다 길면 오른쪽에 빈 공간이 생겨 그리드가 읽히지 않아요.Never to the edge of the screen. A rule longer than its content leaves dead space on the right and the grid stops reading.

05

모션Motion

움직임은 거들 뿐, 주인공은 아니에요.Motion supports; it never leads.

페이지 전환Page transition.85s cubic-bezier(.65,0,.20,1)홈은 스크롤 나열이 아니라 페이지 전환입니다. 세로로 열리고 닫히는 셔터 움직임.The home isn’t a scroll list but a page transition: a shutter opening and closing vertically.
메뉴 오버레이Menu overlay.7s cubic-bezier(.80,0,.20,1)검은 면이 먼저 열리고, 메뉴 항목이 .4s 뒤따라 나타납니다.The black plane opens first; menu items follow .4s behind.

등장(reveal)Reveal16px 아래에서 .6sFrom 16px below, .6s묶인 요소는 .05s씩 차례로(d1·d2)Grouped elements stagger by .05s (d1·d2)

reduced-motion전부 offAll off기기에서 '움직임 줄이기Reduced motion'를 켜면 애니메이션 없이 최종 상태로 바로 보여줍니다.With reduce-motion on, everything renders in its final state with no animation.

움직임은 transform·opacity로만 만듭니다. 레이아웃을 다시 계산하게 만드는 속성(width·top 같은)은 쓰지 않아요. 그래야 저사양 기기에서도 끊기지 않습니다.Motion uses only transform and opacity. Properties that force layout (width, top) are avoided, so it stays smooth on low-end devices.

09

보이스Voice

글도 디자인만큼 규칙이 있어요.Writing has rules too.

케이스는 늘 같은 순서로 씁니다. 문제 → 진단 → 결정 → 결과. 겉으로 드러난 증상이 아니라 진짜 원인을 짚고, 왜 그렇게 결정했는지 이유를 보여준 뒤, 무엇이 증명됐는지로 마무리해요. 끊어지는 불릿 대신 이어지는 문단으로 씁니다.Cases always run in the same order: problem → diagnosis → decision → result. Name the real cause rather than the symptom, show why the call was made, and close on what was proven. Continuous paragraphs, not broken bullets.

수치는 출처와 기준을 함께 적습니다. 어떤 기간의 값인지, 분모가 무엇인지 밝히지 않은 숫자는 쓰지 않아요. 실패한 실험도 실패로 적습니다.Figures come with their source and basis. No number goes in without its window and its denominator. Failed experiments are written as failures.
