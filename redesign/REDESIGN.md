## 확정 사항

1. **키비주얼: 프로젝트 카드 3D 캐러셀** (`redesign/hero.html`)
   - Theo 확정 수치: 카드 16vw 정사각 · 간격 1.24 · 원근 4000 · 카메라 높이 -40% · 속도 0.17 · 세로 위치 1vh · 벌어짐 1.5°
   - 검은 무대, 드래그 회전(관성)+세로 틸트, 뒤 카드 DOF 블러, 자동 회전
   - 카피 락업은 좌하단: 헤드라인(세리프) "Design less, solve more." + 바디 "The more complex the problem, the more it calls for subtraction."
   - 수치 재조정은 `hero.html?tune` 패널로
2. **내비게이션·모션: julianjakob.at 방식** (CSS 실측)
   - 스크롤 나열이 아니라 **페이지 전환(SPA)**: `.page` 컨테이너들이 `transform:scaleY()`로 세로 셔터처럼 열리고 닫힘
   - 모션 토큰: 페이지 전환 `.85s cubic-bezier(.65,0,.20,1)` / 오버레이 `.7s cubic-bezier(.80,0,.20,1)` / 기본 `.3s` · 빠름 `.2s` · 느림 `.4s`
   - 우상단 트리거 텍스트가 Menu ↔ Close로 바뀌고, 전체화면 검정 오버레이가 세로로 열림. 메뉴 항목은 `calc(100vw/6)` 들여쓰기, 호버 시 나머지 항목이 흐려짐
   - 라우팅: `#/`, `#/work`, `#/about`, `#/contact` (케이스는 `#/case/{슬러그}` 예정)
3. **그리드 레퍼런스: julianjakob.at** (CSS 실측 분석 완료)
   - 12컬럼 뷰포트 그리드: 오프셋을 `100vw/12` 단위로 계산 (`calc(100vw/6)` = 2컬럼 들여쓰기)
   - 본문 블록은 2컬럼 들여쓰기, 첫 컬럼은 메타 정보(작은 라벨) 열
   - CSS 변수 체계: `--ui-padding-side`, `--ui-padding-top` 식의 UI 토큰
   - 넉넉한 상하 여백: `clamp(80px, 11vh, 150px)`
4. **본문 형식: 블로그형 → 편집디자인형**
   - 현행 케이스 페이지(제목+문단 나열)를 버리고, 잡지 스프레드처럼 그리드 위에 텍스트·이미지·수치를 배치

## 그리드 원점 일관 규칙 (Theo 지적 2026-07-27)
메타 라벨 = col 1–2. **본문·요약값·수치밴드·구분선 등 모든 콘텐츠 = col 3부터, 페이지 여백(var(--side)) 안에서 정렬.** 수치가 col1(맨 왼쪽)에서 시작해 본문보다 튀거나, 구분선이 화면 끝까지 풀블리드로 나가지 않게. (grid.css/케이스 공통 적용 대상)
